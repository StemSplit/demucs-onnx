# Contributing to demucs-onnx

Thank you for your interest in contributing! This guide covers how to get started.

## Getting Started

1. Fork the repository and clone your fork
2. Install dependencies: `pip install -e ".[dev]"`
3. Run tests: `pytest`
4. Make your changes and ensure tests pass

## Types of Contributions

- **Bug fixes** — open an issue first describing the bug
- **New model exports** — document the model architecture and export process
- **Browser/WASM improvements** — test across Chrome, Firefox, Safari
- **Documentation** — fix typos, clarify examples, add guides
- **Benchmark contributions** — reproducible SDR numbers with methodology

## Pull Request Guidelines

- Keep PRs focused on a single change
- Add tests for new functionality
- Update docs if behavior changes
- Reference related issues with `Fixes #123`

## Reporting Issues

Use [GitHub Issues](https://github.com/StemSplit/demucs-onnx/issues) with:
- OS and Python version
- Minimal reproduction script
- Expected vs actual behavior

## Community

- Questions? Use [GitHub Discussions](https://github.com/StemSplit/demucs-onnx/discussions)
- Built something with demucs-onnx? Share it!
