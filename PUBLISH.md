# demucs-onnx

**PyPI package:** `demucs-onnx`
**GitHub repo:** https://github.com/StemSplit/demucs-onnx
**PyPI page:** https://pypi.org/project/demucs-onnx/

## Publishing

To release a new version:
1. Bump version in `pyproject.toml`
2. Commit and push to the demucs-onnx repo
3. Create a GitHub release to trigger CI publish to PyPI

## Important notes
- This folder has its own standalone git repo connected to https://github.com/StemSplit/demucs-onnx
- All changes should be committed here and pushed to the standalone repo, not the musicai monorepo
